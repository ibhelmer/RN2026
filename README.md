# IT-kursus for ikke-tekniske medarbejdere – Region Nordjylland (2026)

Undervisningsmateriale til IT-kursus for ikke-tekniske medarbejdere i Region Nordjylland, udarbejdet af undervisere fra UCN's IT-uddannelser.

## Formål
Kurset giver et overblik over IT-systemer, netværk, dataudveksling og cybersikkerhed, så deltagerne bedre kan forstå teknologien bag de digitale services og samarbejde med tekniske kolleger og leverandører.

## Emner
- IT-systemer, servere, applikationer og databaser
- Internet, netværk, routere, switche og firewalls
- Dataudveksling og integrationer
- Informationssikkerhed, kryptering, MFA og adgangsstyring
- Zero Trust, SOC og SIEM
- Sundhedsdata, tilgængelighed og beredskab
- AI, muligheder, begrænsninger og ansvarlig brug

## Kursusmaterialer
PowerPoint-præsentationer, PDF-filer og cases kan findes i dette repository, når de er lagt ind. Eksempler på systemarkitektur er illustrative og beskriver ikke nødvendigvis Region Nordjyllands konkrete IT-miljø.
