# IT-kursus for ikke-tekniske medarbejdere – Region Nordjylland (2026)

Undervisningsmaterialer til **IT-kursus for ikke-tekniske medarbejdere i Region Nordjylland**, udviklet med udgangspunkt i UCN's IT-uddannelser.

**Formål:** At give medarbejdere et fælles sprog for IT-systemer, dataudveksling og sikkerhed, så de bedre kan forstå digitale arbejdsgange, samarbejde med IT-fagfolk og stille relevante spørgsmål til teknik og leverandører. Kurset kræver ikke en teknisk baggrund.

## Emner

- **IT-systemer og infrastruktur:** Applikationer, servere, databaser og services.
- **Internet og netværk:** Internettets udvikling, hvordan systemer forbindes, og hvad switche, routere, firewalls og transmissionsforbindelser gør.
- **Dataudveksling:** Integrationer og princippet om, at information skal kunne deles korrekt og sikkert mellem relevante systemer.
- **IT-sikkerhed:** Fortrolighed, integritet og tilgængelighed (CIA), adgangskontrol, kryptering, sikkerhedsforanstaltninger og hændelseshåndtering.
- **Identitet og overvågning:** MFA, MitID, certifikater, Zero Trust, SOC og SIEM.
- **Sundhedssektoren:** Eksempler på håndtering af personoplysninger og sundhedsdata, driftsafbrydelser og cybersikkerhed.
- **AI:** Muligheder, begrænsninger og ansvarlig anvendelse i organisationer.

## Undervisningsmaterialer

Materialerne organiseres her i repositoriet, efterhånden som de bliver lagt ind. PowerPoint-præsentationer og PDF-filer kan hentes via GitHubs filvisning, og praktiske cases kan bruges til diskussion i undervisningen.

> **Status:** Denne README er oprettet, før kursusfilerne er blevet overført fra den lokale undervisningsmappe. Oplistningen ovenfor beskriver kursets emner og er ikke en påstand om, at alle materialerne allerede findes i repositoriet.

## Anvendelse og forbehold

Materialet er beregnet til undervisning og generel forståelse. Eksempler på systemarkitektur og sikkerhed er illustrative og beskriver ikke nødvendigvis Region Nordjyllands faktiske IT-infrastruktur eller interne retningslinjer.

Undgå at tilføje personhenførbare sundhedsoplysninger, adgangskoder, hemmelige nøgler, interne konfigurationer eller andre fortrolige oplysninger til dette **offentlige repository**. Deling af tredjepartsmateriale forudsætter, at ophavsret og eventuelle anvendelsesvilkår tillader offentliggørelse.
